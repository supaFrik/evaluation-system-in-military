# Project Rules & Customizations

- **Auto-invoke Skills**: Agent is fully authorized to automatically read and apply any relevant skills (`SKILL.md`) needed for tasks without prompting for permission or requiring explicit user triggers.
- **Tự động kích hoạt Skill**: Agent tự động đọc và thực thi tất cả các skill phù hợp khi xử lý yêu cầu công việc.
